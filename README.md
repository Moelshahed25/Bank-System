# Bank System

A simple banking system developed in C++ using OOP concepts.

## Features

- User Login
- Add Client
- Delete Client
- List Clients
- Deposit
- Withdraw
- Transfer Between Accounts
- Currency Exchange (EGP ↔ USD)

## Technologies

- C++
- OOP
- File Handling
- Git & GitHub

## Project Structure

- Client Management
- User Management
- Transactions
- Currency Exchange
- Authentication
